# brand/ — biểu tượng chính thức

- `logo-cao-bang.png` — biểu tượng tỉnh Cao Bằng do Văn phòng cung cấp (PNG nền trong suốt, 1280×819, tỷ lệ ngang). **Không tự vẽ, không đổi màu, không kéo méo tỷ lệ.** Dùng ở 3 chỗ (DESIGN mục 1): trang đăng nhập (rộng 112px), thanh bên (rộng 40px trong ô nền trắng bo 4px), favicon.
- `favicon-32.png`, `apple-touch-icon-180.png` (nền trắng, lề 12px) — xuất từ file gốc bằng `sharp` (`fit: contain`), không vẽ lại. Khi Văn phòng thay logo, xuất lại hai file này từ file mới.
- Biểu tượng Đảng (búa liềm) và Quốc huy: chỉ đặt vào đây khi Văn phòng cung cấp file chính thức; không tải từ nguồn không rõ.

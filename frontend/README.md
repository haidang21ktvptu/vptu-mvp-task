# frontend/

Thư mục này sẽ được dựng ở **Giai đoạn 4** (xem `docs/SPEC.md` mục 7): dự án Vite + JavaScript thuần (ES modules) + Tailwind (build, không CDN).

Cấu trúc đích (theo `docs/SPEC.md` mục 6):

```
frontend/
├── index.html
├── vite.config.js
├── .env.example
└── src/
    ├── main.js
    ├── lib/
    ├── auth/
    ├── views/{a1,a2,a3}/
    ├── features/
    ├── components/
    └── styles/
```

Ở Giai đoạn 0, thư mục này còn trống — bản MVP hiện tại vẫn là `index.html` ở gốc repo, chưa được tách vào đây.
